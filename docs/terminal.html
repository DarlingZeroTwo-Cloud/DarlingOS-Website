📟 终端配置

预装终端

Darling OS 预装了：

  • kitty - 高性能 GPU 终端
  • fish - 友好的 shell
  • starship - 漂亮的提示符

打开终端

按 Super + Enter 打开终端。

配置 kitty

配置文件在：~/.config/kitty/kitty.conf

可以改字体大小、颜色、透明度等。

配置 fish

配置文件在：~/.config/fish/config.fish

预装了：

  • alias（ls、grep 彩色）
  • eza（彩色文件列表）
  • bat（语法高亮 cat）
  • zoxide（快速跳转目录）

starship 提示符

提示符会自动显示：

  • 当前目录
  • Git 分支
  • 系统信息
