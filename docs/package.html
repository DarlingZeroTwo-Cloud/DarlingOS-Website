📦 软件包管理

📦 pacman（官方仓库）

sudo pacman -Syu
更新系统 + 所有软件
sudo pacman -S 软件名
安装软件
sudo pacman -Rns 软件名
卸载软件（含依赖）
sudo pacman -Ss 关键词
搜索软件
paccache -rk0
清理缓存

🔨 paru（AUR 仓库）

paru -S 软件名
安装 AUR 软件
paru -Ss 关键词
搜索 AUR 软件
paru -Y
更新 AUR 软件

🛒 星火应用商店

Darling OS 预装了星火应用商店，图形化安装软件，不用敲命令。

在应用启动器里搜索"星火"就能打开。
