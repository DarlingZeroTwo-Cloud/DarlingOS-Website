🖥️ 首次启动

1️⃣ 登录系统

输入你安装时设置的密码，登录进入 Niri 桌面。

2️⃣ 连接网络

点击顶部状态栏的网络图标，连接 WiFi。

如果没有 WiFi 图标，打开终端输：nmtui

3️⃣ 更新系统

打开终端（Super + Enter），输：

sudo pacman -Syu

4️⃣ 配置输入法

预装了 fcitx5 + 拼音输入法。

按 Ctrl + Space 切换输入法。

5️⃣ 设置壁纸

打开 DMS 设置，选择壁纸。

matugen 会自动根据壁纸生成配色方案。

6️⃣ 安装常用软件

打开星火应用商店，搜索安装你需要的软件。

或者用命令：paru -S 软件名
