💿 系统安装

第一步：制作安装 U 盘

  1. 下载 Darling OS ISO 镜像
  2. 用 Rufus / BalenaEtcher 把 ISO 写入 U 盘（至少 4GB）
  3. U 盘启动模式选择 UEFI

第二步：从 U 盘启动

  1. 插入 U 盘，重启电脑
  2. 按 F12 / F2 / Del 进入 BIOS
  3. 选择 U 盘作为第一启动项
  4. 保存并重启，进入 Darling OS Live 系统

第三步：运行安装器

  1. 进入桌面后，双击桌面上的"安装 Darling OS"图标
  2. 选择语言（简体中文）
  3. 选择时区（上海）
  4. 选择键盘布局

第四步：分区设置

  1. 自动分区：最简单，直接清空整个硬盘
  2. alongside 安装：和现有系统共存
  3. 手动分区：自己分配分区

推荐分区方案：

  • EFI 分区：512MB（已存在就不用动）
  • 根分区 /：20GB+（ext4）
  • Swap：4GB（可选）
  • Home 分区：剩余空间（可选）

第五步：用户设置

  1. 输入你的用户名
  2. 设置密码
  3. 设置 root 密码（可选）
  4. 确认安装，等待完成

第六步：重启

  1. 安装完成后，拔出 U 盘
  2. 点击"重启"
  3. 进入 Darling OS 登录界面
