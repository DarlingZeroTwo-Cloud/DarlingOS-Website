📱 Dock 栏

什么是 Dock？

Dock 是屏幕底部的应用栏，类似 macOS 的 Dock。

Darling OS 使用 DMS（Desktop Management System）来管理 Dock。

功能

  • 📌 固定常用应用
  • 🔍 搜索应用
  • 📊 显示运行中的应用
  • 🗑️ 回收站
  • 🎨 液态玻璃效果

自定义

右键点击 Dock 可以：

  • 调整图标大小
  • 设置自动隐藏
  • 添加 / 删除应用
  • 调整位置

配置文件

配置文件在：~/.config/dms/

你可以手动编辑配置文件来自定义 Dock。
