⌨️ 常用命令

📦 软件包管理

sudo pacman -Syu
更新系统
sudo pacman -S 包名
安装软件
sudo pacman -Rns 包名
卸载软件（含依赖）
paru -S 包名
安装 AUR 软件

🖥️ 系统信息

fastfetch
显示系统信息和 logo
btop
系统资源监控
neofetch
显示系统信息

🪟 Niri 窗口管理

Super + Enter
打开终端
Super + Q
关闭窗口
Super + 方向键
切换焦点窗口
Super + 数字
切换工作区

📟 终端

eza
彩色文件列表
bat 文件名
带语法高亮的 cat
zoxide
快速跳转目录

🔧 系统

sudo reboot
重启
sudo poweroff
关机
systemctl status 服务名
查看服务状态
