# Darling OS - Zero Two

基于 Arch Linux 的现代化桌面操作系统。

## ✨ 特性

- 🪟 **液态玻璃风格** - 精美的液态玻璃 UI 设计
- 🪟 **Niri 窗口管理** - 滚动式 Wayland 窗口管理器
- 🇨🇳 **中文优化** - 完整中文支持，输入法预装
- 📦 **预装应用** - 浏览器、办公、开发工具全部预装
- 🎨 **自定义主题** - matugen 动态配色，自动跟随壁纸
- ⚡ **轻量快速** - 基于 Arch Linux，轻量高效

## ⌨️ 常用命令

```bash
# 更新系统
sudo pacman -Syu

# 安装软件
sudo pacman -S 软件名

# 卸载软件
sudo pacman -Rns 软件名

# 显示系统信息
fastfetch
```
